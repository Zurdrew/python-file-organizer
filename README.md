# 📂 Python File Organizer (Automatizador de Diretórios)

Script de automação desenvolvido em Python para varrer diretórios (como a pasta Downloads) e organizar arquivos automaticamente em subpastas com base em suas extensões (Imagens, Documentos, Executáveis, etc.).

**Problema resolvido:** Elimina a necessidade de organização manual de arquivos e demonstra manipulação de sistema operacional via código.

### 🛠️ Tecnologias Utilizadas
* Python
* Bibliotecas: `os`, `shutil`

### 🚀 Destaque Técnico
Prova de conceito para automação de tarefas operacionais e rotinas repetitivas (Task Automation).
